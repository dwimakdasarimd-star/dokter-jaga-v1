# Dokter Jaga v1

Platform clinical education dan practical resources untuk dokter Indonesia.

## Stack
- Next.js 15
- React 19
- TypeScript
- Lucide React

## Routes
- `/` — landing page
- `/cases` — clinical cases
- `/emergency` — emergency quick reference
- `/tools` — practical clinical tools
- `/library` — clinical library
- `/membership` — membership plans

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Repository ini siap di-import ke Vercel sebagai project Next.js.

## Medical disclaimer
Konten ditujukan untuk edukasi. Informasi klinis tidak menggantikan clinical judgment, protokol rumah sakit/fasilitas kesehatan, atau referensi resmi terbaru. Selalu verifikasi dosis, kontraindikasi, interaksi, dan rekomendasi sebelum digunakan dalam praktik.
